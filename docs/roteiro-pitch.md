## Checklist de gravação

- Gravar o site do GitHub Pages, não o `localhost`.
- Se uma API demorar, cortar a espera na edição. Não comentar a demora.
- Subir no YouTube como **Não listado**. Abrir o link numa aba anônima para conferir que ele toca.
- Colar o link no `.txt` da entrega e no README (seção "Equipe e pitch").
